怎麼判（先讀）

LLM 為圖片取了一個標籤（左），而這個標籤最常和 COCO 的某一類（右）的標註框重疊。請判斷左邊這個詞，相對於右邊這個 COCO 類別，是哪一種關係：

1 同義詞（synonym）：指的是同一種東西，換個說法而已，大致可互換。例：sofa → couch、phone → cell phone、television → tv、horses → horse、vehicle → car。

2 較細粒度（finer-grained）：仍是同一個物體或同一群，但描述更具體或換了範圍。例：woman、boy、surfer → person、table → dining table、flowers → vase。

3 非本體（out-of-ontology）：指的是另一個物體、部件或配件，不是右邊那一類本身。例：helmet、hat、shoes → person（人身上的配件）、plate → dining table、cabinet → oven、shelf → book。

4 無法判斷：詞意不明或你不確定。

性別、年齡、職業描述詞（例：man、woman、boy、surfer 相對於 person）請依你自己的判斷歸類，我們想知道你怎麼分。

邊界案例（例：suit、jacket 相對於 person）：「衣物不是人」，我們的分類把它們歸 3，但它們的框常和人重疊。你照字面語意判斷即可，不必考慮定位表現。
